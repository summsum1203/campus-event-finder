# Frontend (React + Vite + Tailwind)

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Copy env file:
   ```bash
   cp .env.example .env
   ```
3. Set API and Supabase values.
4. Run app:
   ```bash
   npm run dev
   ```

## Scripts
- `npm run dev` - start Vite dev server
- `npm run build` - create production build
- `npm run preview` - preview built app
