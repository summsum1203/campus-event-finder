# Backend (Express + Supabase)

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Copy env file:
   ```bash
   cp .env.example .env
   ```
3. Fill in your Supabase credentials.
4. Start API:
   ```bash
   npm run dev
   ```

## Scripts
- `npm run dev` - run with Node watch mode
- `npm run start` - run production server

## API Base
- Local: `http://localhost:4000`
- Health: `GET /api/health`
